# L1 设计交接

浏览器直接打开 `index.html`，无需安装依赖。三个页面均可改数值；代码仅在 `design/l1/`，无生产业务代码、无后端连接。方向待成员选择，`tokens.css` 为候选规范，未选择前不把推荐视为批准。产品口径来源：父任务 OPHE-29。

## 流程与信息架构

1. 首次打开：四字段同屏；资产、储蓄、开销为空，收益率默认 10%，提款率默认 4%。结论「填 4 个数，10 分钟」，三灯塔「未计算」。
2. 输入：当前总资产 → 年新增储蓄 → 年生活开销 → 预期年化收益率。单位常驻右侧；金额右对齐；空白不转换成 0。
3. 改数值即重算目标、进度、缺口、年数，无提交按钮。结论先写已达成，再写金额上最近的未达灯塔和缺口。
4. 展开「假设与计算口径」：可改提款率；「修改收益率」定位主表单中的同一字段，避免两个控件不同步。明说「未计入通胀与税费」。
5. 修改后存本机；刷新或裸页面入口继续记录。显式 `?state=...` 加载固定样例，不受存储影响。保存失败提示「未能保存，先保留本页」，不清空输入。
6. 页尾固定免责声明。原型使用独立设计 namespace，与生产记录隔离；文件方式存储行为因浏览器而异，HTTP 方式验证刷新保留。

异常分支：

| 触发 | 页面呈现 | 恢复动作 |
| --- | --- | --- |
| 共同依赖 A/S/r 任一为空 | 三灯塔未计算，无进度数值 | 补全字段 |
| E 为空 | 灯塔一独立计算，二/三未计算 | 填年开销 |
| r ≤ 0 | 输入下「收益率需大于 0」，三灯塔暂停测算 | 修改收益率 |
| r > 30 | 「收益率需不高于 30%」 | 填范围内假设 |
| E = 0 | 二/三「未填开销」，保留输入 0 | 填大于 0 的开销 |
| A = 0 | 进度为 0，年数照算 | 无需修复 |
| S ≤ 0 且未达目标 | 二/三「按当前储蓄无法到达」 | 修改输入即重算 |
| A<0、E<0、非有限数或超安全整数 | 就地提示，相关结果不计算 | 检查输入 |
| w 为空或超 2.5%–5% | 第三灯塔不计算；超范围提示 | 填合法提款率 |
| 目标已覆盖 | 「已达成 · 100%」「已达成 · 0 年」 | 无需修复 |
| 最少整数年数 >60 | 「60 年以上」 | 不提供假精确年数 |
| 大额 | 万/亿，最多两位小数；不改原始输入 | 无指数记法 |

**待成员确认的口径缺口：** S=0 时 A₁=0，A/A₁ 无有效进度；S<0 时目标和进度会为负。候选呈现保留目标数值，第一灯塔显示「无正储蓄可对照」，百分比和年数为「—」；其余灯塔严格按父任务 S≤0 规则。此行是设计提案，不是已批准的新计算规则。S≤0 且已覆盖目标时，第二/三灯塔仍显示已达成。

## 视觉与可访问性规范

- `tokens.css`：三种色板、12/13/14/16/22/24 字号、4/8/12/16/24/32/48 间距、输入/面板/轨道圆角、无阴影、120/180ms 动效和缓动；各有暗色映射。手机字号见 `ui.css` 断点。
- 金额右对齐；金额/百分比/年数用等宽数字。A 桌面三目标同基线；B/C 金额列对齐。每条进度以自身目标为 100%，轨道长度不可横比目标金额。
- 错误有文字，达成有标签，缺口给金额，不只靠颜色传意。实际文本前景与背景对比度 ≥4.5:1。
- 真实 label；aria-describedby 关联帮助和错误；aria-invalid 标错误；progressbar 提供名称、值和文字。450ms 合并播报结论，避免逐键刷屏。
- Tab 按文档顺序到四输入、假设 summary、提款率、收益率定位链接。原生 details 支持 Enter/Space；焦点环 3px。手机主输入 40px，summary 和评审链接至少 44px。
- 跟随系统暗色。减少动效时进度过渡 0ms；无自动播放或进入动画。

为什么这样选（候选，等待确认）：
1. 进度和缺口并排，减少从百分比换算金额的心算。
2. 金额与年数对齐，便于核对三个目标。
3. 一个结果面板，减少套装卡片的边框噪声。
4. 文案先说记录与测算，收益率明确来自用户假设。
5. 没有插画、渐变或装饰性大数字，把空间留给记录。
6. 系统字体和 CSS 布局无需付费素材与额外库。
7. 三稿共用状态规范，选方向不会改变业务口径。

## 实现成本与边界

只需表单、文字、进度条、折叠区与响应式布局，不指定框架或构建工具。A 在断点切换列数；B 额外维护左栏；C 额外维护节点连线；均不需图表库。生产 localStorage 的迁移、计算精度与单元测试由 Dev 决定并实现，原型 JS 不是生产模块。
