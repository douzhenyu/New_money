# New money

个人理财工具。三个页面：

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/` | 记账 | 资产概览（资产总额、今日变动）+ 记一笔 + 本月流水（按日分组、当日小计） |
| `/watch` | 盯盘 | 自选列表：名称、代码、最新价、涨跌幅、迷你走势；涨跌配色可切换 |
| `/plan` | 测算 | 四个输入 + 三个财富灯塔 |

- 不需要账号、不发任何网络请求、没有后端
- 数据只存在这台设备的浏览器里（`localStorage`）
- 盯盘的行情是**静态示例数据**（`src/watch/quotes.json`），不是实时价格
- 仅记录与测算，不构成投资建议

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 单元测试
npm run build    # 产物在 dist/
npm run preview  # 预览 dist/（内置 SPA 回退，直接打开 /watch 也能进）
```

## 页面在算什么

### 测算（`/plan`）

输入 `A`（当前总资产）、`S`（年新增储蓄）、`E`（年生活开销）、`r`（预期年化收益率），
假设区可改 `w`（提款率，默认 4%）：

| 灯塔 | 目标资产 | 含义 |
| --- | --- | --- |
| 灯塔一 | `A₁ = S / r` | 资产年收益 = 年新增储蓄 |
| 灯塔二 | `A₂ = E / r` | 资产年收益 = 年开销 |
| 灯塔三 | `A₃ = E / w` | 可持续提款覆盖年开销 |

进度 = `min(A / Aₙ, 1) × 100%`；预计年数是使 `A_t ≥ Aₙ` 的最小整数 `t`，
其中 `A_{t+1} = A_t × (1 + r) + S`。未计入通胀与税费。

### 记账（`/`）

- 条目 = 金额 + 分类（九项默认分类）+ 日期（默认今天）+ 备注
- 资产总额 = 测算页填的「当前总资产」− 记账以来的累计支出（测算页没填时显示「—」）
- 今日变动 = `0 − 今日支出`，百分比相对今日开始时的资产总额
- 本月流水按日分组，每天一个当日小计

### 盯盘（`/watch`）

自选标的存 localStorage（默认空 → 空状态）；行情来自静态 JSON；涨跌配色默认红涨绿跌，
可切成绿涨红跌，配置同样存本机。

完整术语与口径边界见 `CONTEXT.md`，开发约定见 `AGENTS.md`。

## 目录

```
src/
  kernel/          测算的计算内核：纯函数 + 单元测试（公式、边界、文案口径都在这里）
  ledger/          记账领域：条目校验、分类、日期口径、概览聚合、金额格式化（纯函数 + 测试）
  watch/           盯盘领域：静态假数据、涨跌方向、迷你走势坐标、配色配置
  storage/         localStorage 读写（按 key 版本化，坏数据丢弃）
  router/          30 行 History API 路由 + 路由匹配测试
  pages/           三个页面：HomePage / WatchPage / PlanPage
  components/      展示组件
  styles/          tokens.css（设计变量）+ global.css
  storage.ts       测算页表单的持久化（未填 ≠ 0）
  App.tsx          路由装配 + 导航 + 页脚
```

## 部署

产物是纯静态文件（`dist/`）。三条路径需要 SPA 回退：任何 `/`、`/watch`、`/plan`
都回 `index.html`（`npm run preview` 已内置；静态托管需自行配置 rewrite）。
